# Data

Put these files in this folder (or set the `S6E3_DATA` environment variable to the folder that holds them):
- `train.csv`, `test.csv`, `sample_submission.csv` from the competition:
  https://www.kaggle.com/competitions/playground-series-s6e3/data
- `WA_Fn-UseC_-Telco-Customer-Churn.csv`: the original IBM Telco customer churn dataset (7,043 rows) that the
  competition data was generated from: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Nothing in this folder is committed to the repository.
