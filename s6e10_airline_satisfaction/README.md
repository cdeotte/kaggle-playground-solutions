# Playground S6E10: Predicting Airline Satisfaction (1st place)

Writeup: [1st place: TFMs and LLMs with tabular data](https://www.kaggle.com/competitions/playground-series-s6e10/writeups/1st-place-tfms-and-llms-with-tabular-data)

The competition data was generated by a GReaT model: a GPT-2 fine-tuned on the original airline satisfaction data and sampled
with a label-first prompt. Our strongest models are GPT-2 classifiers that read each row as the same kind of text:
- **Target first (the "Storyteller"):** how likely is this row's text if it starts with "satisfaction is True", and how likely
  if it starts with "satisfaction is False"? Bayes' rule turns the two likelihoods into a probability.
- **Target last (the "Detective"):** read the row's fields, then predict the label token.

They are stacked with:
- more models built on the same idea: GPT-Neo 125M target first, a GPT-2 child trained with a gentle BCE term, and a
  BatchEnsemble head on features read out of the frozen GPT-2 fold models;
- field transformers and BatchEnsemble MLPs that are pretrained on labelled synthetic "replica worlds" (rows sampled from GReaT
  replicas of the generator, trained on the original data only) before fine-tuning on the competition folds;
- 9 tabular foundation models (zero-shot, full context, raw features), raw-feature XGBoost and RealMLP baselines, and our two
  feature-token transformers (Q-FT and Q-FT v2).

## Results

Our own 27 models alone, stacked by `stack/stack.py` with no public OOF / test pairs, would also have won 1st place:

| Stack | CV | Public LB | Private LB |
|---|---:|---:|---:|
| **The 27 models in this repo** | 0.962836 | 0.96247 | **0.96314** |
| Our final competition submission (25 of these models + public OOF / test pairs) | 0.96290 | 0.96262 | 0.96318 |
| 2nd place on the private LB | | | 0.96308 |

## How to run
1. Put the data in `data/` (see [data/README.md](data/README.md)).
2. Train the level-1 models. Each folder's README has its command(s). Most scripts run the 5 folds (`--folds 0,1` runs a
   subset; finished folds are kept in `parts/` and skipped) and write their pair(s) to `preds/`. Order:
   - GPT models: `models/gpt2_replica` first (it makes the checkpoints they start from); `gpt_hybrid` and `gpt_fold_be` need
     the fold models of `gpt2_target_first --size small`;
   - world-based models: `models/replica_worlds`, then `models/transfer_features`, then `field_be`, `pair_be`, `gpt_fold_be`,
     `m19_source_aug`;
   - Q-FT v2: `side_features.py` first.
3. `python stack/stack.py` prints the stack CV and writes `stack/submission.csv`.

The scripts use the default CUDA device; pick a GPU with `CUDA_VISIBLE_DEVICES`. Most models need one large GPU (the
full-context foundation models need up to ~80 GB).

## Requirements
Base (`requirements.txt`): numpy, pandas, scipy, scikit-learn, xgboost, torch, transformers, huggingface_hub; cuML (RAPIDS)
is optional and makes the stacker fast. Model-specific packages are listed in each folder's README. The GReaT replica needs
its own environment with old pins (`models/gpt2_replica/requirements.txt`).
