# Data

Put these files in this folder (or set the `S6E10_DATA` environment variable to the folder that holds them):
- `train.csv`, `test.csv`, `sample_submission.csv` from the competition:
  https://www.kaggle.com/competitions/playground-series-s6e10/data
- `data.csv`: the original airline satisfaction data (129,880 rows) that the competition data was generated from:
  https://www.kaggle.com/datasets/arseniyshutko/binary-aviation-satisfaction-129k

Nothing in this folder is committed to the repository.
