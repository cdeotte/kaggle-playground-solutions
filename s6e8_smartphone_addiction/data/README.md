# Data

Put these files in this folder (or set the `S6E8_DATA` environment variable to the folder that holds them):
- `train.csv`, `test.csv`, `sample_submission.csv` from the competition:
  https://www.kaggle.com/competitions/playground-series-s6e8/data
- `Smartphone_Usage_And_Addiction_Analysis_7500_Rows.csv`: the original 7,500-row dataset that the competition data was
  generated from: https://www.kaggle.com/datasets/jayjoshi37/smartphone-usage-and-addiction-prediction

Nothing in this folder is committed to the repository.
