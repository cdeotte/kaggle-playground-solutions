# Data

Put these files in this folder (or set the `S6E9_DATA` environment variable to the folder that holds them):
- `train.csv`, `test.csv`, `sample_submission.csv` from the competition:
  https://www.kaggle.com/competitions/playground-series-s6e9/data
- `EV_Adoption_and_Range_Anxiety_Dataset.csv`: the original 10,000-row dataset that the competition data was generated from:
  https://www.kaggle.com/datasets/itzzomkar/ev-adoption-behavior-and-range-anxiety

Nothing in this folder is committed to the repository.
