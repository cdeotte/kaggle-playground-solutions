# Playground S6E9: Predicting Electric Vehicle Purchases (1st place)

Writeup: [1st Place - The AI Relay](https://www.kaggle.com/competitions/playground-series-s6e9/writeups/1st-place-the-ai-relay)

The competition data was generated by a GReaT model: a GPT-2 fine-tuned on the original 10,000-row dataset and sampled with
a label-first prompt. Our final submission is an L2 logistic regression stack of 60 models, all trained on one shared 5-fold
split:
- **XGBoost** on several feature libraries: nested target encodings, response-geometry features, income-mixture EM features,
  LR / rule base margins and the GPT-2 BPE pieces of the income values (how the generator spelled them);
- **neural networks**: RealMLP, TabM and MLPs on the same features, and a family of contrast models;
- **linear models** on target-encoding banks;
- **GPT-2 models** that read rows as text: the target-first generative classifier (Bayes readout), all-target chains,
  " Yes" / " No" classifiers, distilled GPT-2 heads and models on replica likelihood features;
- **four public notebooks** run on our folds (`models/public_models`).

## How to run
1. Put the data in `data/` (see [data/README.md](data/README.md)).
2. Build the shared pieces in this order (each folder's README has its commands):
   - `models/gpt2_replica` (the GReaT replicas; its own environment, `models/gpt2_replica/requirements.txt`);
   - `models/response_features` caches, then `models/income_mixture_xgb` stages 1–2 and its EM cache, then
     `models/neural_contrasts` stages 3–6, then `models/income_mixture_xgb` stage 8 (the teacher of `models/distillation`);
   - `models/nested_te_xgb` builds the target-encoding library that `models/nested_te_realmlp_tabm` also reads;
   - `models/combo_xgb` builds the blocks that `models/te_bank_lr` also reads.
3. Train the models. Most scripts run the 5 folds (finished folds are kept and skipped) and write their pair(s) to
   `preds/`.
4. `python stack/stack.py` finds every pair under `models/*/preds/` and `models/public_models/**/preds/`, prints the stack
   CV and writes `stack/submission.csv`.

The scripts use the default CUDA device; pick a GPU with `CUDA_VISIBLE_DEVICES`. The GPT-2 models and the large caches need
one large GPU.

## Requirements
Base (`requirements.txt`): numpy, pandas, scipy, scikit-learn, xgboost, lightgbm, torch, transformers, huggingface_hub,
pytabkit; cuML (RAPIDS) is optional and makes the GPU logistic regressions and the stacker fast. Model-specific packages are
listed in each folder's README. The GReaT replicas need their own environment with old pins
(`models/gpt2_replica/requirements.txt`).
