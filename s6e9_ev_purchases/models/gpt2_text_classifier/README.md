# GPT-2 fine-tuned as a text classifier

The competition data was generated by a GReaT model (a fine-tuned GPT-2) that wrote every row as text. This model reads
the rows the same way, " Age is 66, Annual_Income_USD is 92887.0, ..., Range_Anxiety_Level is Low, Will_Buy_EV is", and
a pretrained GPT-2 is fine-tuned per fold to score the next token: logit(" Yes") - logit(" No"), trained with the
cross-entropy over these two logits. No engineered features: the raw values with GPT-2's own tokenizer.

Per fold: fine-tuning on 95% of the outer-train rows (fixed column order, 3 epochs, batch 128, AdamW, 5% warmup then
linear decay, bf16 autocast, seed 7); the checkpoint with the best AUC on the other 5% (checked every 1000 steps) predicts
the validation fold and the test rows; test = mean of the 5 fold models.

| Pair | Runs | OOF AUC |
|---|---|---:|
| `gpt2_small_text_cls` | gpt2 (124M), lr 3e-5 | 0.944778 |
| `gpt2_text_cls_blend3` | logit mean of three runs: gpt2 lr 3e-5, gpt2-medium (355M) lr 2e-5, gpt2-medium lr 3e-5 | 0.945366 |

```
python train.py all                                  # or one pair, e.g. python train.py gpt2_small_text_cls
python train.py --run gpt2_medium_lr2e5 --folds 0    # one run and fold per process, to run folds in parallel
```
`--save-model` also keeps the fine-tuned weights in `checkpoints/`. Each run keeps its finished folds in `runs/parts/`
and its OOF / test pair in `runs/preds/`; the pairs go to `preds/`. A fold takes about 35 minutes with gpt2 and about 1.7
hours with gpt2-medium on one large GPU. Needs torch and transformers (gpt2 / gpt2-medium are downloaded from the
Hugging Face hub).
