# Data

Put these files in this folder (or set the `S6E5_DATA` environment variable to the folder that holds them):
- `train.csv`, `test.csv`, `sample_submission.csv` from the competition:
  https://www.kaggle.com/competitions/playground-series-s6e5/data
- `f1_strategy_dataset_v4.csv`: the original 101,371-row dataset that the competition data was generated from:
  https://www.kaggle.com/datasets/aadigupta1601/f1-strategy-dataset-pit-stop-prediction

Nothing in this folder is committed to the repository.
