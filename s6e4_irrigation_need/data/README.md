# Data

Put these files in this folder (or set the `S6E4_DATA` environment variable to the folder that holds them):
- `train.csv`, `test.csv`, `sample_submission.csv` from the competition:
  https://www.kaggle.com/competitions/playground-series-s6e4/data
- `irrigation_prediction.csv`: the original 10,000-row dataset that the competition data was generated from:
  https://www.kaggle.com/datasets/miadul/irrigation-water-requirement-prediction-dataset

Nothing in this folder is committed to the repository.
